# ☠️ JUJUTSU: CURSED CLASH

A fan-made, browser-based 3D arena brawler inspired by *Jujutsu Kaisen*. The veil has fallen over Shibuya. Play as a Grade 1 sorcerer and exorcise five escalating waves of cursed spirits before facing the Special Grade **Patchwork Curse**.

Built with Three.js, procedural geometry, canvas textures, and a fully procedural Web Audio soundtrack — no external game assets or build step required.

## Play

Serve the project root with any static file server:

```bash
cd /path/to/PlayGround
python3 -m http.server 3002
# open http://localhost:3002
```

In the OMGithub runtime, `./start.sh` launches the managed preview server instead.

## Controls

| Action | Desktop | Mobile |
| --- | --- | --- |
| Move | `WASD` / arrow keys | Left joystick |
| Aim camera | Mouse (click to lock) or drag | Drag the arena |
| Light combo | Left mouse / `J` | **STRIKE** |
| Cursed heavy strike | Right mouse / `K` | **CURSED** |
| Dash (brief i-frames) | `Shift` / `Space` | **STEP** |
| Black Flash ultimate | `E` | **呪 FLASH** |
| Pause / resume | `Esc` or `P` | Pause button |

Land hits to build Cursed Energy. At 100%, Black Flash tears open an area attack that also slows time. Clear all five waves to lift the veil.

## Features

- Five hand-tuned waves, a multi-arm Special Grade boss, and three enemy classes.
- Third-person camera with lock-on-free action combat, combo ranks, pickups, and ranks S–D.
- Fully procedural Shibuya-night arena: torii gate, neon city, wet asphalt, cursed veil, embers, bloom, and film grain.
- Procedural hero/enemy rigs and animations; no model downloads.
- Responsive desktop and mobile HUD with touch controls.
- Automatic low-quality mode for software renderers (`?quality=low` / `?quality=high` to override).
